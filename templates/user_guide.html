Dashboard & Monitor

Mengakses Dashboard

Dashboard utama dapat diakses melalui http://localhost:5000 dengan login default:

Username: admin

Password: admin123

Fitur Dashboard

  • Real-time clock dengan format digital
  • Statistics Cards: Total Jadwal, Live Sekarang, Scheduled, Completed
  • System Monitoring: CPU, Memory, Disk, Network speed
  • Quick Actions ke berbagai halaman fitur

Live Streaming

Setup Live Stream

  1. Navigasi ke menu Live Streaming
  2. Isi form setup:
    • Title - Judul stream
    • Description - Deskripsi konten
    • Video File - Pilih video dari gallery
    • RTMP Server - Pilih platform
    • Stream Key - Input key dari platform
    • Schedule Time - Tanggal & waktu mulai
    • Duration - Durasi dalam menit (opsional)
    • Repeat Daily - Auto schedule untuk hari berikutnya

Platform Support

YouTube: rtmp://a.rtmp.youtube.com/live2/
Facebook: rtmps://live-api-s.facebook.com:443/rtmp/
Instagram: rtmps://live-upload.instagram.com:443/rtmp/
Twitch: rtmp://live.twitch.tv/app/

Auto Start/Stop System

  • Scheduled Start: Background thread cek tiap 60 detik, auto start ffmpeg saat waktu tiba
  • Auto-Stop Timer: Stop ffmpeg otomatis berdasarkan durasi yang diset
  • Notifications: Kirim notifikasi Telegram saat status berubah

Jadwal Management

Create Schedule

  1. Menu Jadwal → Tambah Jadwal
  2. Form Fields:
    • Title - Judul video/stream
    • Description - Deskripsi konten
    • Scheduled Start Time - Tanggal & waktu
    • Video File - Pilih dari gallery
    • Token File - Akun YouTube yang digunakan
    • Privacy Status - public/unlisted/private
    • Auto Start/Stop - Checkbox options
    • Made for Kids - YouTube setting
    • Repeat Daily - Otomatis schedule

Bulk Scheduling

Upload Excel file dengan format:

Column A Title
Column B Description
Column C Scheduled Start Time (YYYY-MM-DD HH:MM:SS)
Column D Video File
Column E Token File
Column F Privacy Status
Column G Category ID
Column H Tags (comma-separated)

Upload System

Video Gallery

  • Upload Video: Drag & drop atau browse file
  • Supported Formats: MP4, AVI, MOV, WMV, FLV, MKV
  • Auto Thumbnail: Generate otomatis saat upload
  • Metadata: Input title, description, tags

Bulk Upload Queue

  1. Tambah videos ke queue
  2. Set schedule per video
  3. Monitor progress real-time
  4. Auto-retry untuk failed uploads

Auto Upload Configuration

  • Enabled/Disabled: Toggle auto upload
  • Offset Hours: Jeda sebelum upload (default: 2 jam)
  • Check Interval: Frekuensi cek (default: 30 menit)
  • Delete After Upload: Hapus file setelah sukses

OAuth & Tokens

YouTube Token Authorization

  1. Menu Tokens → Authorize New Token
  2. Upload client_secret.json dari Google Cloud Console
  3. Click Authorize
  4. Login ke Google account & grant permissions
  5. Token disimpan otomatis untuk user tersebut

Stream Keys Management

  • Fetch from YouTube: Auto get semua stream keys dari channel
  • Create New Stream: Generate stream key baru langsung dari aplikasi
  • Stream Mapping: Mapping antara stream ID dan nama stream
  • Import/Export: Backup stream configurations

AI Integration

Gemini AI Setup

  1. Menu Gemini Settings
  2. Input API Key dari Google AI Studio
  3. Choose model: gemini-pro, gemini-pro-vision
  4. Set custom prompt template
  5. Configure temperature (0.0 - 1.0)

AI Metadata Generator

Fitur AI dapat mengenerate otomatis:

  • ✅ Titles - Clickbait & SEO optimized
  • ✅ Descriptions - Detail dengan hashtag
  • ✅ Tags - Relevant & trending tags
  • ✅ Categories - Auto categorization
  • ✅ Made for Kids - Content classification

Notifikasi Telegram

Setup Telegram Bot

  1. Chat dengan @BotFather
  2. Kirim /newbot - Create new bot
  3. Dapatkan Bot Token
  4. Chat dengan @userinfobot untuk dapat Chat ID
  5. Menu Telegram Settings → Input Token & Chat ID

Jenis Notifikasi

  • 🎬 Stream Starting - Saat stream dimulai
  • ⏹️ Stream Ended - Saat stream selesai
  • ⏰ Schedule Reminder - 15 menit sebelum jadwal
  • ❌ Error Notifications - Jika ada error
  • 📤 Upload Updates - Progress upload

Troubleshooting

Common Issues

FFmpeg Not Found

sudo apt update

sudo apt install ffmpeg

Token Expired

  1. Delete old token di Tokens page
  2. Re-authorize dengan fresh login
  3. Check client_secret validity

Stream Failed

  1. Check RTMP server URL
  2. Verify stream key valid
  3. Check internet connection
  4. Review ffmpeg logs di ffmpeg_logs/

Upload Error

  1. Check YouTube quota
  2. Verify video format compatible
  3. Check token permissions
  4. Review error message detail
